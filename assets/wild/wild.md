# hero-readme — in the wild

Twenty popular projects, each given a **fully bespoke** animated hero — its own background, palette, and an animation that *shows what the project actually does*. No shared template: a phone mirrors to a screen for scrcpy, a request arcs to a server for axios, shapes fall for matter-js, a QR code assembles for QR-Code-generator.

Each was produced by the skill's author → **independent-reviewer** → revise loop (the reviewer renders several animation frames and critiques), then verified by hand. All animate on GitHub with no `<script>`.
