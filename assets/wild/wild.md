# hero-readme — in the wild

A **bespoke, brand-colored, concept-matched** set for **103 popular repositories**. Each repo's README was analyzed by an agent (which chose the brand palette, tagline, and a concept motif), then rendered by hero-readme. Per repo: a **hero** plus three marketing motifs — **before → after**, **boot-up**, and **side-by-side** — all animating on GitHub with no `<script>`.

> Agent-designed, generator-built. Brand colors and "concept motif" are the agent's best read of each project. Sorted by stars.
