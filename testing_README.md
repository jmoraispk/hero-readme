# hero-readme — concept lab 🧪

A scratch page for **marketing motifs**: eye-catching ways to show off a hero. Each
is one self-contained animated SVG (pure CSS, no `<script>`) that loops right here
on GitHub. These are *ideas to react to* — not part of the skill yet. Tell me which
should graduate into the skill and/or the main README.

> Motion loops; if you have "reduce motion" on, each shows its finished frame.

---

## 1. Before → After  ·  *the reveal*

A plain, boring README suddenly gains an animated hero at the top, and the content
shifts down to make room. The single clearest "why you want this."

## 2. Boot-up  ·  *it assembles itself*

The hero builds in front of you: the flow-field background ignites, the wordmark

## 3. Grayscale → color  ·  *generic to authentic*
